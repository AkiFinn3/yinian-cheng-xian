## 四、如何看报错

游戏崩溃或行为异常时，Godot 会输出红色报错。获取方式：

1. 在 Godot 编辑器里运行游戏
2. 看**底部「输出」面板**（Output）
3. 红色文字就是错误
4. 复制完整报错给我（**不要只复制最后一行**）

**常见报错含义：**

| 报错关键词 | 含义 |
|---|---|
| `Parse Error` | 语法错误，通常是缩进或括号问题 |
| `Invalid call` / `Invalid get index` | 变量名写错，或数组越界 |
| `Attempt to call function ... in base 'null instance'` | 对象不存在 |
| `Node not found` | 场景节点路径错误 |

## 五、测试原则

1. **改前先测**：确认改之前是好的，才知道改后坏没坏。
2. **一次只测一个功能**：同时改多个功能，出问题无法定位。
3. **记录，不靠记忆**：测完立刻勾选表格。
4. **失败要复现**：说不清怎么复现的 bug，等于没找到。
