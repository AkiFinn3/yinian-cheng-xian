## 三、备份方式（双重保险）

### 第一层：Git（推荐，日常用）

```bash
# 查看当前状态
git status

# 查看历史
git log --oneline

# 提交新版本
git add -A
git commit -m "v0.2.0 阶段8：三种妖兽"

# 看某个版本改了什么
git show <提交号>

# 撤销未提交的改动（回到上次提交）
git checkout -- .

# 回到某个历史版本（谨慎）
git checkout <提交号>
```

### 第二层：文件夹副本（每次阶段完成时）

```bash
cd /Users/yu/Documents/Game
cp -R yinian-cheng-xian "备份/v0.2.0-$(date +%Y%m%d)-阶段8-三种妖兽"
```

**命名格式：** `v版本号-日期-阶段-简述`
