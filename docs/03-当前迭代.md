## 一、境界总览

采用**内丹十境 + 五仙**体系（每个复合名拆为独立境界）：

| # | 境界 | 分阶 | 定位 |
|---|---|---|---|
| 0 | **炼己** | 初期 / 中期 / 圆满 | 炼心，最基础 |
| 1 | **筑基** | 初期 / 中期 / 圆满 | 筑就道基 |
| 2 | **炼精** | 初期 / 中期 / 圆满 | 炼化精元 |
| 3 | **化炁** | 初期 / 中期 / 圆满 | 精化为炁 |
| 4 | **炼炁** | 初期 / 中期 / 圆满 | 淬炼真炁 |
| 5 | **化神** | 初期 / 中期 / 圆满 | 炁化为神 |
| 6 | **炼神** | 初期 / 中期 / 圆满 | 淬炼元神 |
| 7 | **返虚** | 初期 / 中期 / 圆满 | 神返虚空 |
| 8 | **炼虚** | 初期 / 中期 / 圆满 | 炼化虚空 |
| 9 | **合道** | 初期 / 中期 / 圆满 | 合于大道 |
| 10 | **◈ 仙道三选一** | 鬼仙 / 人仙 / 地仙 | **不可逆分支** |
| 11 | **神仙** | 不分阶 | 阳神成就 |
| 12 | **天仙** | 不分阶 | 飞升之极 |

**共 10 个凡俗境界（30 小阶）+ 3 个仙阶 = 33 级。**

> 仙境不分三阶段：从「仙道三选一」起，每级只有一档。

炼精初期 → 中期 → 圆满 ┃

化神初期 → 中期 → 圆满 ┃

                ↓
        ◈ 仙道三选一 ◈
        鬼仙 ／ 人仙 ／ 地仙
                ↓
             神仙
                ↓
             天仙
```

## 二、仙道三选一（核心机制）

**炼虚合道·圆满后触发，不可逆。** 这是本阶段最重要的设计——给 roguelike 一个身份抉择。

| 仙道 | 道途 | 立即获得 | 后续功法倾向 |
|---|---|---|---|
| **鬼仙** | 阴神不散，出窍夺舍 | 暴击率 **+20%**，最大生命 **-20** | 暴击、爆发、高风险 |
| **人仙** | 长生久视，肉身不坏 | 最大生命 **+60**（回满），减伤 **+10** | 均衡、续航 |
| **地仙** | 住世长生，不慕飞升 | 减伤 **+25**，最大生命 **+40**，移速 **-20** | 防御、坚守 |

**设计意图：**

- **鬼仙** = 玻璃大炮，靠暴击秒怪，但容错低
- **人仙** = 稳，适合新手，没有明显短板
- **地仙** = 铁王八，慢但打不死，靠磨

三条路线对应三种玩家性格，且都有明确取舍（不是「哪个强选哪个」）。

## 三、功法池

### 3.1 凡人十境（每境 4 种，共 40 种）

每境固定四种：**剑气伤害 / 减伤 / 移速 / 暴击率**，数值逐境递增。

| 境界 | 剑气 | 减伤 | 移速 | 暴击 |
|---|---|---|---|---|
| 炼己 | 剑气诀 +8 | 护体灵气 +4 | 疾风步 +25 | 凝神 +5% |
| 筑基 | 御剑术 +18 | 金钟罩 +10 | 踏云步 +45 | 心眼 +10% |
| 炼精 | 精元剑气 +26 | 精血护体 +13 | 精行步 +60 | 精觉 +13% |
| 化炁 | 炁冲剑脉 +36 | 炁盾 +18 | 罡气行云 +80 | 炁感 +17% |
| 炼炁 | 炁御剑 +48 | 炁墙 +24 | 缩地成寸 +105 | 炁视 +22% |
| 化神 | 神识御剑 +62 | 神念护体 +30 | 神行术 +130 | 神觉 +27% |
| 炼神 | 炼神剑意 +80 | 神元护体 +38 | 踏虚而行 +160 | 洞神 +33% |
| 返虚 | 虚空剑意 +100 | 返虚护体 +46 | 返虚游 +195 | 洞虚 +39% |

## 五、成长节奏

```
凡人十境 × 3 小阶 = 30 次功法三选一
+ 仙道三选一 1 次
+ 神仙 1 次
+ 天仙 1 次
= 共 33 次成长决策

**33 次决策，流程明显拉长。** 这是按「流程太短」的反馈做的调整。

## 六、关键技术改动

### 6.1 现状问题

- `level: int`（`main.gd:78`）只有一个等级，无法表达境界
- 功法硬编码在 `choose_skill()` 的 `match` 里（`main.gd:366-372`），3 个分支

**扩到 40 种功法 + 33 级境界，必须重构。**

### 6.2 新数据结构

```gdscript
# 境界表：10 个凡俗境界，每境 3 阶（仙阶在第二刀加入）
const REALMS := [
    {
        "name": "炼己",
        "stages": ["初期", "中期", "圆满"],
        "xp": [24, 30, 38],
        "skills": ["剑气诀", "护体灵气", "疾风步", "凝神"],
    },
    ...
    { "name": "合道", "xp": [308, 328, 350], "skills": ["大道剑诀", ...] },
]

# 仙道三选一（不可逆）
const IMMORTAL_PATHS := {
    "鬼仙": { "desc": "暴击率 +20%，最大生命 -20", "crit": 20.0, "max_hp": -20 },
    "人仙": { "desc": "最大生命 +60 并回满，减伤 +10", "max_hp": 60, "armor": 10, "heal": true },
    "地仙": { "desc": "减伤 +25，最大生命 +40，移速 -20", "armor": 25, "max_hp": 40, "speed": -20.0 },
}

# 功法表：统一用 stat + value
const SKILLS := {
    "剑气诀": { "desc": "剑气伤害 +8",  "stat": "sword", "value": 8 },
    "凝神":   { "desc": "暴击率 +5%",   "stat": "crit",  "value": 5 },
    "太虚不灭": { "desc": "最大生命 +200，减伤 +80", "stat": "multi",
                  "effects": [{"stat": "max_hp", "value": 200}, {"stat": "armor", "value": 80}] },
}
```

**效果统一用 `stat` + `value`**，`choose_skill()` 只需 `match stat:` 处理 6 种属性（sword/armor/speed/crit/max_hp/attack_speed），而不是 40 个分支。多效果功法用 `multi` + `effects` 数组。

### 6.3 状态变量

| 现在 | 改为 |
|---|---|
| `level: int` | `realm_index: int` + `stage_index: int` |
| `next_level_xp: int` | 从 `REALMS[realm_index]["xp"][stage_index]` 读 |
| — | 新增 `crit_bonus: float` |
| — | 新增 `immortal_path: String`（鬼仙/人仙/地仙，空=未选） |
| — | 新增 `path_choice_pending: bool`（仙道选择界面） |

### 6.4 妖兽难度

`pick_enemy_type()` 现用 `level`，改为总进度：

```gdscript
func get_progress() -> int:
    if realm_index >= 10:         # 已成仙
        return 30 + (realm_index - 10) * 3
    return realm_index * 3 + stage_index
```

`level_bonus = mini(progress, 6)`，保证境界越高岩甲兽越多。

## 十二、我的评价

**这个体系比原方案好，理由：**

1. **内丹六阶有真实出处**，玩家（尤其修仙题材受众）认得，代入感强
2. **五仙分级是道教原典**，鬼仙最低、天仙最高，天然有阶梯感
3. **仙道三选一给了 roguelike 最需要的「不可逆抉择」**——这比单纯堆数值有意思得多
4. **仙境不分阶**解决了「后期升级太碎」的问题，终局节奏更利落

**唯一的顾虑：** 21 次升级 + 2974 修为，一局可能偏长（15 分钟以上）。这个可以实机后调，不影响结构。
