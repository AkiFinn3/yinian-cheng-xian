## 二、A · 破境劫难战 ✅ 已实现（v0.7.0）

### 2.1 触发时机

每次**破境**时触发（小境界「圆满」→ 下一境界「初期」），共 9 次凡人破境 + 仙阶破境。

```
炼己圆满 → 【劫难】→ 筑基初期
筑基圆满 → 【劫难】→ 炼精初期
...
炼虚圆满 → 【劫难】→ 合道初期
合道圆满 → 【仙道三选一】（不触发劫难，改为仙道抉择）
```

### 2.2 劫难类型

**化神之前（炼己 / 筑基 / 炼精 / 化炁 / 炼炁 破境时）：**

| 劫难 | 内容 |
|---|---|
| **强敌劫** | 随机 1 只或 2 只强化妖兽（血量 ×3、伤害 ×1.5） |

**化神之后（化神 / 炼神 / 返虚 / 炼虚 / 合道 破境时）：**

| 劫难 | 内容 | 设计意图 |
|---|---|---|
| **天罚雷劫** | 1 只雷兽（高攻高速），期间天降落雷 | 考验走位 |
| **心魔劫** | 1 只「心魔」（复制玩家外观，高血） | 心理压迫 |
| **斩三尸** | **3 只**尸魔（善尸/恶尸/执尸），同时出现 | 考验输出与走位 |

**随机规则：** 化神后每次破境从三种中随机一种。

### 2.3 劫难奖励

**打完劫难获得「劫难奖励」三选一**（强于普通功法）：

| 奖励 | 效果 |
|---|---|
| 道基稳固 | 最大生命 +40 并回满 |
| 杀伐果断 | 剑气伤害 +50 |
| 身法通玄 | 移速 +60，攻击间隔 -0.05 秒 |

**每次劫难后固定给这三选一**（后续可按劫难类型差异化）。

### 2.4 流程

```
修为满 → 破境界面（金色，显示「第 N 劫」）
         ↓
    劫难战（场上只留劫难敌人，不补普通妖兽）
         ↓ 全部击杀
    劫难奖励三选一
         ↓ 选完
    境界推进 + 补满普通妖兽
```

## 三、D · 无限地图（v0.8.0）

### 3.1 核心改动

| 现在 | 改为 |
|---|---|
| 玩家位置钳制在屏幕内 | **不钳制**，可无限走 |
| 无摄像机 | 加 `Camera2D` 跟随玩家 |
| 妖兽在屏幕边缘生成 | 在**玩家周围环形区域**生成（屏幕外） |
| 剑气超出屏幕消失 | 超出**视野**一定距离消失 |
| 背景铺满屏幕 | 只画**可视区域**的网格 |

### 3.2 技术方案

```gdscript
var camera: Camera2D          # 跟随玩家
var view_size: Vector2        # 视口尺寸

func get_view_rect() -> Rect2:
    return Rect2(player_pos - view_size / 2.0, view_size)

func world_to_screen(p: Vector2) -> Vector2:
    return p - player_pos + view_size / 2.0
```

**UI 绘制**用 `draw_set_transform(-camera_offset)` 切回屏幕坐标，现有 UI 代码不用大改。

### 3.3 妖兽生成

```
在玩家周围 半径 R 的圆环上随机取点（R = 屏幕对角线/2 + 100）
```

保证永远从视野外出现。

## 四、C · 障碍物（v0.8.0）

### 4.1 类型

| 类型 | 可破坏 | 效果 |
|---|---|---|
| **岩石** | ❌ | 阻挡玩家、妖兽、剑气 |
| **古木** | ✅ | 阻挡，可被剑气打碎（3 下） |
| **灵草** | ✅ | 不阻挡，打碎回 5 生命 |

### 4.2 生成

按世界坐标网格程序化生成（种子固定，同一局内一致）：

```
每 400×400 的格子，20% 概率生成一个障碍物
```

### 4.3 碰撞

简易圆形碰撞：
- 玩家移动后检测，若重叠则推回
- 妖兽同理
- 剑气命中障碍物则消失（可破坏的扣血）
