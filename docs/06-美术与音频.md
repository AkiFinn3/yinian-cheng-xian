## 一、现状

游戏画面全部由 `scripts/main.gd` 的 `_draw()` 函数用几何图形绘制：

| 元素 | 绘制方式 | 颜色 |
|---|---|---|
| 背景 | `draw_rect` 铺满 | `#173d32` 深绿 |
| 地面纹理 | 48px 间隔的 2×2 小方块 | `#285344` |
| 玩家 | 矩形 | 青白色 |
| 妖兽 | 矩形 | `#bd3e85` 粉色（受击变白） |
| 剑气 | 圆 | 黄白色 |
| 血条 | `draw_rect` | 红/灰 |

**优点：** 零成本、无版权问题、改色改大小即改视觉。
**缺点：** 观感粗糙，缺乏辨识度。

## 四、AI 生成素材（备选）

如果使用 AI 生成像素图：

- 工具：本地 Stable Diffusion 或免费在线工具
- 提示词风格模板：`pixel art, 2D top-down, chinese xianxia style, dark fantasy, 32x32 sprite, transparent background`
- **风险：** AI 生成素材的商用许可需确认，且风格一致性难保证
- **建议：** 优先用 CC0 素材，AI 素材只作补充

### 8.1 工具选型（2026-10-28 核实官方源）

| 工具 | 免费方式 | macOS 支持 | 透明 PNG | 结论 |
|---|---|---|---|---|
| **Pixelorama** | MIT 开源，完全免费无广告 | ✅ 官方 `.dmg`，含 Apple Silicon 签名 | ✅ | **✅ 采用** |
| LibreSprite | 免费开源 | ⚠️ 官方 wiki 曾注明 Mac 因 Skia 问题不可用 | ✅ | ❌ 不采用 |
| Piskel | 免费，网页版有广告，无付费版 | ✅ 网页 + 桌面 | ✅ | 🔵 备选 |

**为什么选 Pixelorama：**

1. 完全免费且无广告（不是「免费但有广告」或功能阉割）
2. macOS 官方支持，提供 `.dmg` 安装包
3. **它本身就是用 Godot 开发的**——与项目同一引擎，导出格式天然兼容
4. 零基础友好：界面现代，有图层、调色板、动画帧
5. 可以先零安装试用网页版，觉得好再装桌面版

**官方入口：**

| 渠道 | 地址 |
|---|---|
| 官网 | https://pixelorama.org/ |
| GitHub Releases | https://github.com/Orama-Interactive/Pixelorama/releases |
| itch.io | https://orama-interactive.itch.io/pixelorama |
| 网页版（免安装） | https://orama-interactive.github.io/Pixelorama/ |

> **注意**：Steam 上的 Pixelorama 是付费的（用于支持项目），但**免费版功能完全相同**，
> 不要误买。从官网 / GitHub / itch.io 下载都是免费的。

### 8.2 安装步骤（Mac）

1. 打开 https://pixelorama.org/ ，点 Download
2. 选择 macOS 版本，下载 `.dmg`
3. 双击 DMG，把 Pixelorama 图标拖进「应用程序」文件夹
4. 从启动台或应用程序文件夹打开

**如果提示「Pixelorama 已损坏，无法打开」：**

这不是文件真的损坏，是 macOS Gatekeeper 拦截了未公证的应用。两种解决方法：

- **方法一（推荐）**：打开「系统设置」→「隐私与安全性」→ 页面下方找到被拦截的提示 → 点「仍要打开」
- **方法二（终端）**：
  ```bash
  xattr -d com.apple.quarantine /Applications/Pixelorama.app
  ```

### 8.3 素材规格

| 类别 | 尺寸 | 说明 |
|---|---|---|
| 玩家角色 | 32 × 32 | 透明背景，俯视角或正面 |
| 普通妖兽 | 32 × 32 | 轮廓要容易识别 |
| 首领 | 64 × 64 | 体型更大 |
| 飞剑 / 弹幕 | 16 × 16 | 方向清晰 |
| 地面图块 | 16 × 16 | 可平铺 |

**统一风格要求：**
- 有限配色（建议单角色 4-8 色）
- 清晰轮廓，避免细节糊成一团
- 像素边缘硬朗，**不使用**抗锯齿、模糊、过多渐变
- 背景必须透明（PNG alpha 通道）

### 8.6 Godot 导入设置（关键）

**已在 `project.godot` 配置：**

```ini
[rendering]
textures/canvas_textures/default_texture_filter=0
```

`0` = **Nearest（最近邻）**。像素游戏必须这样设，否则素材放大后会变模糊。
这项设置已生效，后续导入的 PNG 会自动使用最近邻过滤。

**导入单张图片时还要检查：**
1. 在 Godot 文件系统面板选中 PNG
2. 右侧「导入」标签页
3. 确认 **Filter** 为 `Nearest`（继承项目设置即可）
4. 确认 **Mipmaps** 关闭（像素图不需要）
5. 点「重新导入」
