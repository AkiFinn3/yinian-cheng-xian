## 一、现状

游戏画面全部由 `scripts/main.gd` 的 `_draw()` 函数用几何图形绘制：

| 元素 | 绘制方式 | 颜色 |
|---|---|---|
| 背景 | `draw_rect` 铺满 | `#173d32` 深绿 |
| 地面纹理 | 48px 间隔的 2×2 小方块 | `#285344` |
| 玩家 | 矩形 | 青白色 |
| 妖兽 | 矩形 | `#bd3e85` 粉色（受击变白） |
| 剑气 | 圆 | 黄白色 |
| 血条 | `draw_rect` | 红/灰 |

**优点：** 零成本、无版权问题、改色改大小即改视觉。
**缺点：** 观感粗糙，缺乏辨识度。

## 二、正式美术计划（阶段 11）

### 风格定位

- **2D 像素风**
- 参考方向：中式修仙 + 暗色调秘境
- 分辨率基准：建议 32×32 或 48×48 像素单位
- 调色板：深绿背景 + 高饱和敌人 + 金色特效（剑气、暴击）

### 需要的素材清单

| 类别 | 内容 | 数量 | 优先级 |
|---|---|---|---|
| 角色 | 玩家待机、移动（4 方向） | 1 套 | 高 |
| 角色 | 玩家受击、死亡 | 2 帧 | 中 |
| 妖兽 | 妖狼 待机/移动/受击 | 1 套 | 高 |
| 妖兽 | 疾风雀 待机/移动/受击 | 1 套 | 高 |
| 妖兽 | 岩甲兽 待机/移动/受击 | 1 套 | 高 |
| 特效 | 剑气飞行、命中、暴击 | 3 套 | 高 |
| 特效 | 升级光效、死亡消散 | 2 套 | 中 |
| UI | 血条、经验条、功法图标 | 若干 | 中 |
| 背景 | 秘境地面、装饰物 | 1 套 | 低 |

## 三、免费素材来源（零成本）

| 来源 | 网址 | 许可 | 说明 |
|---|---|---|---|
| Kenney | kenney.nl | CC0 | 大量免费 2D 素材，可商用 |
| OpenGameArt | opengameart.org | 混合（逐个确认） | 社区素材库 |
| itch.io 免费区 | itch.io/game-assets/free | 混合 | 注意逐个看许可 |
| CraftPix 免费区 | craftpix.net/freebies | 自定义许可 | 需确认是否可商用 |

**使用规则：**

1. 下载前先确认许可证（CC0 最安全）。
2. 记录来源 URL、作者、许可证到本文件。
3. 需要署名的必须署名。
4. **不确定许可的，一律不用。**

## 四、AI 生成素材（备选）

如果使用 AI 生成像素图：

- 工具：本地 Stable Diffusion 或免费在线工具
- 提示词风格模板：`pixel art, 2D top-down, chinese xianxia style, dark fantasy, 32x32 sprite, transparent background`
- **风险：** AI 生成素材的商用许可需确认，且风格一致性难保证
- **建议：** 优先用 CC0 素材，AI 素材只作补充

**音量控制：** 需要 音效 / 音乐 两条独立滑杆，存入设置。
