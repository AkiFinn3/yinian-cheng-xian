# 00 · 项目总纲

> 项目代号：**YNXX** ｜ 类型：独立游戏开发 ｜ 阶段：原型迭代

---

## 一、一句话定义

《一念成仙》是一款 **2D 像素风修仙肉鸽游戏**：玩家操控修士，在秘境中与妖兽战斗，获取修为、突破境界、选择功法，逐步挑战更强的敌人。

---

## 二、产品目标（分三层）

| 层级 | 目标 | 判定标准 |
|---|---|---|
| **第一层：可玩** | 一局完整、有胜负、有成长感的游戏循环 | 陌生人能不看说明玩 5 分钟不困惑 |
| **第二层：可测** | 可以打包给外部玩家试玩的测试版 | 导出 macOS 版本，能独立运行 |
| **第三层：可评估** | 收集反馈，判断是否值得投入商业化 | 有真实玩家反馈数据 |

**当前处在第一层的前半段。** 核心战斗循环已通，但还没有完整的一局（无计时、无波次、无胜负结算）。

---

## 三、范围边界

### 现在做（IN SCOPE）

- 2D 俯视角战斗
- 自动攻击 + 走位躲避（操作简化，适合手机/键鼠）
- 妖兽种类扩展与难度递增
- 功法构筑（Roguelike 的 build 深度）
- 关卡/波次/首领
- 基础 UI、存档、音效
- macOS 平台导出

### 现在不做（OUT OF SCOPE）

| 不做的内容 | 原因 |
|---|---|
| 联网 / 多人 | 成本极高，与单机肉鸽定位不符 |
| 复杂剧情 / 对话系统 | 优先玩法，剧情后置 |
| 大量正式美术 | 玩法未验证前投入美术是浪费 |
| 内购 / 广告 / 付费内容 | 未验证游戏质量前不商业化 |
| 移动端适配 | 先做 PC，验证后再考虑 |
| 3D | 项目定位是 2D 像素风 |

> **任何超出范围的请求，先讨论是否值得，再动手。**

## 四、技术栈

| 项 | 选择 | 说明 |
|---|---|---|
| 引擎 | **Godot 4.7.2** | 免费开源，2D 友好，导出 macOS 免费 |
| 语言 | **GDScript** | 语法接近 Python，零基础友好 |
| 渲染 | GL Compatibility | `project.godot` 已配置，兼容性最好 |
| 版本控制 | **Git** | 本地仓库，无需联网 |
| 美术 | 程序绘图 → 后期像素素材 | 当前 `_draw()` 画方块/圆 |
| 音频 | 免费素材库（后期） | 见 `06-美术与音频.md` |

**引擎版本锁定 4.7.2，不随意升级。** 升级需单独评估并记录。

## 五、成本原则

- **预算目标：0 元。**
- 引擎免费、Git 免费、素材优先用 CC0 协议。
- 未经明确确认，**不购买**任何资产、插件、服务或订阅。
- 如需付费，必须同时给出：价格、必要性、免费替代方案。

---

## 六、协作规则（摘要）

完整规则见根目录 `AGENTS.md`，核心三条：

1. **改代码前先读实际文件**，不凭记忆。
2. **改代码前先备份**，绝不覆盖唯一可运行版本。
3. **一次只做一个小功能**，测试通过再叠加。

---

## 七、成功标准

这个项目算"成功"的最低标准：

- [ ] 能导出 macOS 独立可运行版本
- [ ] 一局游戏有明确的开始、过程、胜负
- [ ] 至少 3 种妖兽、6 种功法
- [ ] 连续玩 3 局不崩溃、无明显 bug
- [ ] 有至少 1 名外部玩家完整试玩并给出反馈

达到以上标准，再讨论商业化。
