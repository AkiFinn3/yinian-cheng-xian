## 二、已完成功能清单

### 角色与操作

### 战斗

| 功能 | 实现 | 参数 |
|---|---|---|
| 妖兽追踪 | `update_enemy()` | 速度 75 px/s，直线追踪 |

| 受击闪白 | `enemy_hit_flash` | 0.12 秒 |
| 伤害文字提示 | `message_text` | 屏幕上方显示 0.6 秒 |

### 成长

| 功能 | 实现 | 参数 |
|---|---|---|
| 修为奖励 | `kill_enemy()` | 按妖兽类型：妖狼 +10 / 疾风雀 +8 / 岩甲兽 +25 |
| 升级阈值 | `kill_enemy()` | `next_level_xp = 等级 × 30` |
| 功法三选一 | `begin_upgrade()` | 1/2/3 键 或 鼠标点击，悬停高亮 |
| 剑气诀 | `choose_skill()` | 剑气伤害永久 +10 |
| 护体灵气 | `choose_skill()` | 每次受伤减少 5 |
| 疾风步 | `choose_skill()` | 移动速度永久 +35 |

### 流程

| 功能 | 实现 |
|---|---|
| 妖兽死亡与重生 | `kill_enemy()` → `spawn_enemy()` |
| 玩家死亡 | `player_hp <= 0` → `is_game_over = true` |
| 死亡结算界面 | `_draw()` |
| R 键重开 | `_unhandled_input()` → `restart_game()` |

## 四、已知边界与问题

### 功能性缺失（不是 bug，是还没做）

| 缺失 | 影响 | 计划阶段 |
|---|---|---|
| ~~只有 1 种妖兽~~ | ✅ 阶段 8 已解决 | ~~阶段 8~~ |
| 功法池只有 3 种且不叠加 | 构筑深度不足 | 阶段 9 |
| 无计时/波次/胜负 | 一局没有终点 | 阶段 10 |
| 无主菜单/暂停/设置 | 只能直接进游戏 | 阶段 11 |
| 无存档 | 每次重开从零 | 阶段 11 |
| 无音效/音乐 | 手感单薄 | 阶段 11 |
| 全程序绘图 | 视觉粗糙 | 阶段 11 |
| 未打包 | 无法分发 | 阶段 12 |

### 技术性隐患

| 隐患 | 位置 | 说明 |
|---|---|---|
| 单文件 722 行 | `main.gd` | 所有系统耦合在一个脚本，后续扩展会变难 |
| 单妖兽同屏 | `enemy_*` 系列变量 | 阶段 8 用"类型数据表"缓解，但仍只能同时存在 1 只妖兽；多妖兽同屏需阶段 10 再重构 |
| 无单元测试 | — | 全靠手动测试（已用临时脚本验证，未纳入仓库） |
| 屏幕尺寸每帧查询 | `_process()` | `get_viewport_rect()` 每帧调用，影响极小但可优化 |
