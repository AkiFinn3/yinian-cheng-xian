## 一、四套系统的定位

当前游戏只有「境界 + 功法」两条成长线。新增四套系统是为了**让构筑有层次**：

| 系统 | 定位 | 获取方式 | 使用方式 |
|---|---|---|---|
| **法器** | 被动装备 | 首领/精英掉落 | 自动生效，最多带 3 件 |
| **符箓** | 一次性消耗品 | 妖兽掉落 | 按键释放，有次数 |
| **飞剑** | 主动技能 | 境界突破解锁 | 冷却后按键释放 |
| **阵法** | 场地增益 | 劫难奖励/首领掉落 | 放置在地面，站进去生效 |

**设计原则：** 四套系统都**不替代**现有的自动剑气，而是叠加在上面，避免操作复杂度爆炸。

## 二、法器（被动装备）

### 2.1 槽位

**3 个槽位**，同类型不可重复装备（防止叠满同一个）。

### 2.2 法器清单（12 件）

| 法器 | 稀有度 | 效果 |
|---|---|---|
| 青锋剑匣 | 凡 | 剑气伤害 +15 |
| 玄龟甲 | 凡 | 减伤 +10 |
| 疾风铃 | 凡 | 移速 +40 |
| 聚灵珠 | 凡 | 修为获取 +15% |
| 雷纹印 | 灵 | 暴击率 +8% |
| 回春玉 | 灵 | 每秒回复 1.5 生命 |
| 破军令 | 灵 | 剑气射程 +80 |
| 千机匣 | 灵 | 攻击间隔 -0.06 秒 |
| 太虚镜 | 宝 | 剑气 +1 道（散射） |
| 不灭灯 | 宝 | 生命低于 30% 时减伤 +30 |
| 噬魂幡 | 宝 | 击杀回复 3 生命 |
| 天罡印 | 宝 | 暴击伤害 ×2.5（原 ×2） |

### 2.3 掉落

| 来源 | 概率 |
|---|---|
| 精英妖兽 | 15% |
| 首领 | 100%（3 选 1） |
| 劫难奖励 | 20% 额外掉一件 |

    ...

## 三、符箓（一次性消耗品）

### 3.1 机制

- 掉落获得，**最多携带 5 张**
- 按 **Q** 键释放当前选中的符箓
- 按 **E** 键切换符箓
- 释放后消耗

### 3.2 符箓清单（6 种）

| 符箓 | 效果 | 冷却 |
|---|---|---|
| **火球符** | 向最近妖兽发射火球，范围爆炸 80px，伤害 60 | 无 |
| **冰封符** | 冻结全场妖兽 1.5 秒 | 无 |
| **雷击符** | 对全场妖兽造成 40 伤害 | 无 |
| **护身符** | 3 秒无敌 | 无 |
| **疾行符** | 3 秒移速 +150% | 无 |
| **聚灵符** | 立即吸收全场修为晶石 | 无 |

> 全部「无冷却」——因为是消耗品，靠数量限制而非冷却。

### 3.3 掉落

- 普通妖兽 8%
- 精英 40%
- 首领 100%（3 张）

### 3.4 数据结构

```gdscript
const TALISMANS := {
    "火球符": {"desc": "发射火球，范围爆炸 60 伤害", "type": "fireball"},
    ...
}
var talismans: Array[String] = []      # 背包（最多 5）
var selected_talisman: int = 0
```

## 四、飞剑（主动技能）

### 4.1 机制

- **境界突破解锁**，不需要捡
- 按 **空格** 释放
- 有冷却（8 秒）

### 4.2 解锁表

| 解锁境界 | 飞剑 | 效果 |
|---|---|---|
| 筑基·初期 | 一叶飞剑 | 直线穿透，伤害 ×3 |
| 化炁·初期 | 三才剑阵 | 3 道扇形，伤害 ×2 |
| 炼神·初期 | 万剑归宗 | 12 道环形，伤害 ×2 |
| 天仙 | 斩仙飞刀 | 全屏一道巨型剑气，伤害 ×10 |

### 4.3 数据结构

```gdscript
const FLYING_SWORDS := {
    "一叶飞剑": {"desc": "直线穿透，伤害 ×3", "count": 1, "spread": 0.0, "mul": 3.0, "pierce": true},
    ...
}
var unlocked_sword: String = ""        # 当前可用飞剑
var sword_cooldown: float = 0.0
```

## 五、阵法（场地增益）

### 5.1 机制

- 掉落获得，最多带 2 个
- 按 **F** 键在脚下放置
- 阵法持续 15 秒，站进去生效，可随时离开
- 同时只能有 1 个阵生效

### 5.2 阵法清单（4 种）

| 阵法 | 效果 | 半径 |
|---|---|---|
| **聚灵阵** | 阵内修为获取 +50% | 180 |
| **杀阵** | 阵内妖兽每秒受 15 伤害 | 160 |
| **护体阵** | 阵内减伤 +40% | 150 |
| **疾风阵** | 阵内移速 +80%，攻速 +20% | 200 |

### 5.3 数据结构

```gdscript
const FORMATIONS := {
    "聚灵阵": {"desc": "阵内修为 +50%", "radius": 180.0, "type": "xp"},
    ...
}
var formations: Array[String] = []      # 背包（最多 2）
var active_formation: Dictionary = {}   # {name, pos, life}
```

## 六、按键分配

| 键 | 用途 | 现状 |
|---|---|---|
| WASD | 移动 | 已用 |
| 1/2/3 | 三选一 | 已用 |
| R | 重开 | 已用 |
| **Q** | 释放符箓 | 新增 |
| **E** | 切换符箓 | 新增 |
| **空格** | 释放飞剑 | 新增 |
| **F** | 放置阵法 | 新增 |
| **TAB** | 查看装备 | 新增 |

**冲突检查：** 现有只用了 WASD/1/2/3/R，无冲突。

## 七、分阶段交付

| 版本 | 内容 | 理由 |
|---|---|---|
| **v0.10.0** | 法器系统（被动装备，最简单） | 只加属性，不改战斗逻辑 |
| **v0.11.0** | 符箓 + 飞剑（主动技能） | 需要按键与冷却框架 |
| **v0.12.0** | 阵法（场地系统） | 需要世界坐标与范围判定 |
